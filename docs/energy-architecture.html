Retail Energy 360

From 5 raw smart-meter files to a named retention list — a deliberately simple declarative bronze → silver → gold pipeline in SQL. Auto Loader ingests, Expectations clean, Materialized Views aggregate, and a single ai_classify call labels each customer's latest message. No Visual Data Prep, no Genie Code, no ML — just the pipeline. Synthetic French retail-energy data.

1Bronze · Auto Loader

Streaming ingestion

Four Streaming Tables ingest the raw CSV and nested-JSON files from the Volume with STREAM read_files. Auto Loader tracks files incrementally — a re-run only reads what's new.

bronze_customers · bronze_consumption
bronze_billing · bronze_interactions
2Bronze · Reference MV

Tariff reference

The 11 tariff plans are static reference data, so they load as a Materialized View (batch read_files) that also derives is_flat_tariff — the crux of the retention story.

ref_tariff_plans
3Silver · Expectations

Clean, typed, enriched

Typing + Expectations (drop / fail / warn) on customers, consumption and billing. A stream-static join attaches the tariff plan and is_flat_tariff to each customer.

silver_customers · silver_consumption · silver_billing
4Silver · Nested JSON

Flatten the interactions

The interaction JSON lands as struct columns; dot notation (interaction.category, sentiment.score) flattens them into clean typed columns — no UDFs.

silver_interactions
5Gold · Materialized View

Customer energy profile

One row per customer: six features (avg_daily_kwh, peak_consumption_pct, seasonal_ratio …) plus a rule-based consumption_segment.

gold_customer_energy_profile
6Gold · ai_classify

Interaction topic

A single ai_classify call labels the ~80 distinct messages, fanned back to each customer's latest contact — ~350× fewer LLM calls than classifying every row.

gold_customer_topics
7Gold · Retention list

At-risk customers

Peak Heavy + flat tariff + billing dispute, ranked by estimated annual revenue at risk. The call list the whole pipeline exists to produce.

gold_at_risk_customers
8Unity Catalog

Governed consumption

AI/BI dashboards, Genie, apps or notebooks read the gold tables: access, lineage and audit governed by Unity Catalog.
